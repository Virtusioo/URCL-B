
# B Language Compiler for URCL!

## What is B?
* The language that preceded C.
* Word-based syntax.
* Uses the opposite ABI to C (no varargs, left-to-right argument passing).

## How optimized is this compiler?
* Includes a peephole optimizer.
* Does not use SSA.

## Is this complete? 
* Approximately 80% complete.

## How to Compile
* Run the Makefile.

## Dependencies
* `make` or `mingw32-make`
* `g++` compiler
